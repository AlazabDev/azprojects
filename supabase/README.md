# دليل تشغيل ونشر قاعدة البيانات والسياسات الأمنية (AzProjects SQL & Backend Engine)
مؤسسة العزب للمقاولات والاستشارات المعمارية

---

## 📂 محتويات مجلد قاعدة البيانات السحابية `/supabase`:

1. **`01_schema.sql` (ملف بناء الجداول والعلاقات والفهارس)**:
   - يحتوي على كافة الجداول الـ 15 المتكاملة:
     - `profiles`: ملفات المستخدمين المرتبطة بـ `auth.users`.
     - `projects`: المشروعات المعمارية (بما فيها إحداثيات الموقع، الميزانية، وربط أمر عمل دفترة #17 وMagicPlan).
     - `project_team_members`: جدول أعضاء الفريق وتخصيص صلاحيات التعديل، الميزانية، واعتماد المهام.
     - `project_phases`: المراحل الهندسية القياسية ونسب الإنجاز.
     - `tasks`: المهام التنفيذية، الأولويات، وقوائم التحقق (Checklists JSONB).
     - `documents`: المخططات والتراخيص وعقود المشاريع مع تمييز العام والخاص.
     - `suppliers`: الموردين والمقاولين الباطن وتقييماتهم.
     - `cost_items`: بنود التكاليف المالية وربطها بدفترة.
     - `payments`: سندات الصرف والتحويلات المالية.
     - `magicplan_designs`: المخططات الهندسية السحابية ثلاثية وثنائية الأبعاد.
     - `whatsapp_messages`: وسائط ومحادثات الواتساب الميدانية.
     - `daftra_sync_records`: سجلات المزامنة المالية مع دفترة.
     - `notifications`: الإشعارات والتنبيهات المجدولة.
     - `audit_logs`: سجلات التدقيق والأمان.
     - `app_settings`: إعدادات النظام وقواعد التنبيهات.
   - الفهارس الذكية (`Indexes`) لتسريع الاستعلامات والبحث.
   - الـ Triggers التلقائية لتحديث حقل `updated_at`.

2. **`02_security_and_rls_policies.sql` (ملف سياسات الأمان على مستوى الصف RLS)**:
   - **سياسة أمان العميل (Client Isolation)**:
     - يرى العميل فقط المشروعات الخاصة به (`client_id = auth.uid()`).
     - يرى فقط المخططات المصرح بها للعميل (`is_public = TRUE`).
     - يرى جدول المدفوعات والمراحل الخاصة بمشروعه فقط.
     - تُحجب عنه بنود التكاليف الداخلية والمصروفات الإدارية.
   - **سياسة أمان الموظفين والمهندسين (Staff & Task Isolation)**:
     - يرى الموظف المهام الموكلة إليه تحديداً (`assigned_to = auth.uid()`).
     - يمكنه تحديث حالة المهمة وقائمة التحقق التابعة له فقط.
     - يرى المهندسون المشروعات والمستندات المشاركين فيها عبر جدول `project_team_members`.
   - **سياسة الإدارة والمالك (Owner / PM Full Access)**:
     - تحكم كامل وصلاحيات مطلقة لإدارة الميزانيات، التكاليف، إنشاء المشروعات، وتعيين المهام.
   - **الدوال الأمنية والمشغلات (Security Functions & Triggers)**:
     - دالة `handle_new_user` لربط مستخدمي Supabase Auth بجدول `profiles` فور التسجيل.

3. **`03_seed_data.sql` (ملف البيانات الأولية الحية)**:
   - غرس مشروع أرابيسك الحي المعماري (المتصل بأمر عمل دفترة 17 ومخطط MagicPlan السحابي).
   - المراحل الهندسية الخمس، المهام الميدانية، بنود التكاليف، وبيانات الموردين المعتمدين.

---

## 🚀 طريقة تطبيق الملفات في Supabase Dashboard:

1. ادخل إلى لوحة تحكم مشروعك في [Supabase](https://supabase.com/dashboard).
2. افتح قسم **SQL Editor**.
3. قم بنسخ وتشغيل محتوى **`01_schema.sql`** أولاً لبناء الجداول.
4. قم بنسخ وتشغيل محتوى **`02_security_and_rls_policies.sql`** لتفعيل سياسات الأمان RLS وحماية البيانات.
5. (اختياري) قم بتشغيل **`03_seed_data.sql`** لإدراج البيانات التجريبية الحية.
