## 🌟 نظرة عامة
تُعد **AzProjects** المنصة المركزية الرقمية لمؤسسة العزب لإدارة عمليات المقاولات والتشطيبات الداخلية والخارجية. تم بناء المنظومة لتوحيد دورة حياة المشروع بدءاً من التعاقد والمخطط المعماري وحتى التسليم النهائي، مع ربط مباشر ومؤمن بين الطاقم الهندسي في الموقع، الإدارة المالية، والعميل.

---

## 🚀 المميزات والوحدات الرئيسية

### 1. 🏗️ إدارة المشاريع والمراحل الهندسية (Project Lifecycle)
* **المراحل الإنشائية والتشطيبات:** تتبع مراحل الأعمال (أعمال عظم، تشطيبات أرابيسك، كهروميكانيكا MEP، دهانات، وتسليم نهائي).
* **لوحة التحكم والمؤشرات:** متابعة نسب الإنجاز التراكمية، ومقارنة الصرف الفعلي بالميزانية المعتمدة.
* **إدارة المهام الميدانية:** توزيع المهام على المهندسين المشرفين والمقاولين الفرعيين وتتبع أوقات التنفيذ.

### 2. 💰 الربط المالي والمحاسبي المتكامل (Daftra ERP Integration)
* مزامنة آلية وفورية مع نظام دفترة المحاسبي عبر واجهات البرمجة الخلفية المباشرة.
* تتبع سندات القبض، الصرف، الفواتير، وعروض الأسعار لكل مشروع بشكل منفصل.
* إدارة الموردين والمقاولين ومستحقات الدفعات بنقرة زر.

### 3. 📐 استيراد وتفحص المخططات المعمارية (MagicPlan Cloud v2)
* استيراد الرسومات ثلاثية الأبعاد والمخططات المعمارية مباشرة من تطبيق MagicPlan.
* استعراض المقاسات وحساب الكميات تلقائياً لتقليل نسب الهدر في المواد والتشطيبات.

### 4. 🤖 المساعد الهندسي بالذكاء الاصطناعي (AI Engineering Agents)
* **Google Gemini API:** تحليل التقارير الفنية، حساب التقديرات المالية، وتوليد خطط الأعمال والمواصفات.
* **Microsoft Azure AI Foundry Agent:** وكيل ذكي مخصص للرد على الاستفسارات الفنية ودعم اتخاذ القرارات الهندسية.

### 5. 💬 مركز الاتصال وإشعارات واتساب (WhatsApp Business API)
* إرسال تحديثات دورية وتقارير الإنجاز المصورة للعملاء مباشرة عبر واتساب.
* استلام استفسارات وملاحظات العملاء وربطها بسجلات المشروع تلقائياً.

### 6. 📁 التخزين السحابي الآمن للمستندات (MinIO / S3 Object Storage)
* مستودع مركزي لحفظ صور الموقع، عقود العمل، رخص البناء، ومستندات الاستلام مع تشفير عالي الأمان.

### 7. 👤 بوابة العميل الشفافة (Client Portal)
* إتاحة وصول مخصص للعميل لمتابعة مراحل تشطيب وحدته يوماً بيوم، والاطلاع على الفواتير ونسب التقدم بكل شفافية.

## 🔐 القواعد الأمنية وعزل الأسرار (Security Directives)

تتبع المنظومة قواعد أمان صارمة وغير قابلة للتجاوز:
1. **حظر كامل للأسرار في كود المتصفح (Zero Secrets in `VITE_`):**
   * المتغيرات التي تبدأ بـ `VITE_` مخصصة **فقط** للقيم العامة (عناوين الروابط، مفاتيح Supabase العامة المحمية بـ RLS، وأسماء النطاقات).
   * يُمنع منعاً باتاً وضع أي مفتاح API سري أو كلمة مرور ببادئة `VITE_` حتى لا تتسرب في حزمة الجافاسكربت للمتصفح.
2. **نمط البروكسي الخلفي (Backend Proxy Pattern):**
   * كافة الخدمات التي تتطلب مفاتيح سرية (Daftra, MagicPlan, Azure AI, MinIO, WhatsApp, Gemini) يتم استدعاؤها حصراً من خلال الخادم الخلفي عبر مسارات `/api/*` في `server.ts`.
3. **حماية الصفوف RLS في PostgreSQL:**
   * جميع جداول قاعدة البيانات محمية بنسبة 100% بسياسات Row Level Security لتصفير أخطاء الأمان وتطبيق أسلوب `(SELECT auth.uid())` لسرعة الأداء وحجب البيانات الحساسة.

## ⚙️ إعداد وتشغيل المشروع

### المتطلبات الأساسية
* بيئة تشغيل **Node.js** (الإصدار 20 أو أحدث).
* مدير الحزم **npm** أو **pnpm**.

### خطوات التثبيت والتشغيل المحلي

1. **استنساخ المستودع والدخول للمجلد:**
   ```bash
   git clone <repo-url>
   cd azprojects
   ```

2. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

3. **إعداد ملف متغيرات البيئة:**
   * قم بإنشاء ملف `.env` في جذر المشروع بناءً على النموذج المرفق في `.env.example`.

4. **تشغيل بيئة التطوير المباشرة (Dev Mode):**
   ```bash
   npm run dev
   ```
   * سيعمل التطبيق والسيرفر على المنفذ: `http://localhost:3000`

5. **فحص الأنواع البرمجية والتدقيق:**
   ```bash
   npm run lint
   ```

6. **بناء المشروع للإنتاج (Production Build):**
   ```bash
   npm run build
   ```

7. **تشغيل حزمة الإنتاج:**
   ```bash
   npm start
   ```

## 🔑 دليل متغيرات البيئة (.env)

| المتغير | البيئة | الوصف |
| :--- | :--- | :--- |
| `NODE_ENV` | سيرفر | وضع التشغيل (`development` أو `production`) |
| `PORT` | سيرفر | منفذ الخادم (افتراضياً `3000`) |
| `VITE_APP_URL` | فيت / عام | رابط النطاق الأساسي للواجهة |
| `VITE_SUPABASE_URL` | فيت / عام | رابط مشروع Supabase العام |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | فيت / عام | المفتاح العام (Anon/Publishable) لـ Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | **سيرفر فقط** | مفتاح إدارة Supabase السري |
| `DAFTRA_SUBDOMAIN` | سيرفر / فيت | النطاق الفرعي لمؤسسة العزب في دفترة |
| `DAFTRA_API_KEY` | **سيرفر فقط** | المفتاح السري للربط المحاسبي مع دفترة |
| `MAGICPLAN_API_KEY` | **سيرفر فقط** | مفتاح الربط السري مع منصة MagicPlan |
| `MAGICPLAN_CUSTOMER_KEY` | **سيرفر فقط** | معرف العميل السري لدى MagicPlan |
| `GEMINI_API_KEY` | **سيرفر فقط** | مفتاح Google Gemini AI السري |
| `AZURE_AI_PROJECTS_ENDPOINT` | **سيرفر فقط** | نقطة الاتصال بمشروع Azure AI Foundry |
| `MINIO_ACCESS_KEY` / `SECRET_KEY` | **سيرفر فقط** | مفاتيح الوصول لخادم التخزين السحابي MinIO |
| `WHATSAPP_ACCESS_TOKEN` | **سيرفر فقط** | رمز الوصول السري لواجهة واتساب للأعمال |
| `SQL_HOST` / `SQL_PASSWORD` | **سيرفر فقط** | بيانات الاتصال المباشر بقاعدة بيانات PostgreSQL |

## 🗄️ قواعد البيانات وتهجيرات Supabase

توجد كافة ملفات التهجير وبناء المخططات داخل المجلد:
`supabase/migrations/`

* **`01_schema.sql`**: الجداول الأساسية، الأنواع المخصصة، والفهارس.
* **`02_security_and_rls_policies.sql`**: السياسات الأمنية الأولى وقواعد RLS.
* **`06_zero_errors_zero_warnings_master.sql`**: **الملف الماسي الحاسم** لتصفير كافة تحذيرات وأخطاء مدقق سوبابيس (0 Errors, 0 Warnings) وتأمين كافة الجداول والـ Views.
